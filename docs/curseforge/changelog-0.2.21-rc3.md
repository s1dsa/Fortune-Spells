# Fortune Spells 0.2.21-rc3

Minecraft 1.20.1 · Forge 47.4.0 · Java 17

同一个 JAR 支持迎战 1.6.0 和 1.6.2，可搭配铁魔法 3.15.5.1 或 3.16.4。客户端和专用服均使用此包。

| 铁魔法 | 配套前置 |
| --- | --- |
| 3.15.5.1 | Iron’s Patreon Lib 1.0.1 |
| 3.16.4 | Iron’s Lib 2.1.0 |

保留 Curios、GeckoLib 和 playerAnimator，移出旧版 Fortune Spells 后再放入 rc3。超位墨水的阶位提示改由物品自身显示。

维护者实玩暂未发现问题。独立审查在迎战 1.6.0 搭配铁魔法 3.15.5.1 时确认了进服、两项 Mixin 和三种材料酿造觐见卷轴。其余三组完成配包校验。

The same JAR supports Meet Your Fight 1.6.0 and 1.6.2 with Iron’s Spells ’n Spellbooks 3.15.5.1 or 3.16.4. Install matching dependencies on both the client and dedicated server. Use Iron’s Patreon Lib 1.0.1 for the older spellbook version and Iron’s Lib 2.1.0 for the newer one.
