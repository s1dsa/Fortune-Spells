# 0.2.17

The in-game mod name is now **迎战铁魔法联动（铁魔法扩展）**. The Forge mod list, resource pack description and player guides use the new name. The mod ID remains `fortune_spells`, so existing worlds can upgrade by replacing the previous JAR.

游戏内名称更新为**迎战铁魔法联动（铁魔法扩展）**。Forge 模组列表、资源包说明和玩家指南已同步。模组 ID 仍为 `fortune_spells`，已有存档可直接替换旧版 JAR 升级。
